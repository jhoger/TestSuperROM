Super ROM consists of four modules, Write ROM, Lucid

Super Rom is however far more than merely four

This term "integrated" has really become a buzz word
in the software promotion game and has been
misapplied more often than not. If software is really
integrated it needs to meet several essential
requirements.

a. All the software needs to be "up" at the same
time. This means that you can go from one
application to another with a couple of
keystrokes and then back again without losing
anything.

b. All the programs need to be able to have cross
compatibility. This means that whatever work you
generate or produce with one application needs to
be able to be used on any other of the
applications quickly and easily. To be truely
integrated you need to be able to take the

product of one application and use it as part of
any other.

c. All the programs need to have similar user
interfaces. Key combinations for features and
